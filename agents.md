# AGENTS.md

## Проект

Карты метро для приложения pMetro. Репозиторий: `git@github.com:pMetro/pMetro-maps.git`.
Карты скачиваются с официального сайта pmetro.su и раздаются через проект pmetro.github.io.

## Структура

```
maps/<Город>/          # 243+ городов, по одному каталогу на город
  Metro.map            # конфигурация города (INI: опции отображения, список линий)
  <Линия>.map          # конфигурация отдельной линии (например L1.map)
  Metro.cty            # параметры города (INI: Name, CityName и т.п.)
  <Город>.vec          # векторная карта (рисование линий/станций, свой формат: Size/W/PenColor/BrushColor/F)
  Metro.trp            # трамвайные/наземные ветки (INI: [Line N] Stations=...)
pmz/                   # временная: *.pmz-архивы (фактически zip), извлечённые из установщика
download/              # временная: *.zip для загрузки (создаёт pack.cmd)
get-maps.cmd           # скачать pMetroSetup.exe и извлечь из него *.pmz
unpack.cmd             # распаковать pmz/* в maps/
pack.cmd               # собрать pmz/* в download/*.zip
```

- `maps/` — единственная часть, которая коммитится. `pmz/`, `download/`, `*.pmz`, `*.zip` — временные, в .gitignore.
- Файлы текст (INI + кастомный .vec), с CRLF. Не переформатируйте, не меняйте кодировку и порядок полей.
- Имена файлов соответствуют линиям в `.map`-конфигах; `.cty` и `Metro.trp` — один на город.

## Обновление карт (ежемесячная процедура)

1. `get-maps.cmd` — скачивает pMetroSetup.exe (нужен `innoextract`), извлекает `app/*.pmz` в `pmz/`.
2. `unpack.cmd` — распаковывает `pmz/*.pmz` в `maps/` (нужен 7-Zip, в скрипте путь `D:\winApps\7z`).
3. Проверить изменения: `git status` / diff по `maps/`.
4. Закоммитить изменения в `maps/` с сообщением `update from pMetro.su`.
5. `pack.cmd` — соберёт zip'ы в `download/`.
6. Изменившиеся zip'ы скопировать в проект **pmetro.github.io**, папку `download`, и продолжить работу там.

## Правила для агентов

- Не редактируйте .vec/.map/.cty/.trp вручную, кроме намеренных исправлений ошибок в карте; это данные, а не код.
- При правках данных — минимальный diff, сохраняйте CRLF, не трогайте города, которые не затрагиваются задачей.
- Не коммитьте `pmz/`, `download/`, `*.pmz`, `*.zip`, `.idea/`.
- Скрипты `.cmd` — Windows-специфичные; не портируйте в bash без просьбы.
- Нет тегов и releases; история коммитов — преимущественно `update from pMetro.su`.
